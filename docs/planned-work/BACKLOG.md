- 등록일: 2026-10-04 (계층 작업명 작업 중 발견)
- 증상: Paperclip 3100이 30초마다 10~30초씩 응답을 멈춘다(`/api/health` 포함). 아무 작업도 안 할 때도 발생, 제목 연쇄 플러그인을 꺼도 같음.
- 원인(관측): Paperclip의 "terminal issue workspace reaper"가 30초마다 실행 작업공간 기록 50개씩 git 상태를 검사한다. 정리되지 않은 기록이 137개(9/30~10/3 생성, 모두 agent os 저장소 `/mnt/c/...` 한 곳, 원래 작업은 완료 84·취소 53)이고, /mnt/c git 검사가 건당 약 1.4초라 서버가 그동안 멈춘다. 전부 "보관 불가"로 건너뛰어 계속 반복된다.
- 영향: 대시보드·플러그인 화면이 가끔 수십 초 느려짐.
- 주의: 정리기가 실제 "보관"을 하면 작업 폴더 정리 명령이 저장소에 닿을 수 있으므로, 기록을 함부로 닫거나 정리기를 강제로 돌리지 않는다.
- 다음 단계(승인 필요): 이 137개 기록이 저장소를 건드리지 않고 닫히는 방법을 Paperclip 소스로 확인 → 격리 복원본에서 시험 → 운영 적용. 프로젝트 작업공간 방식을 바꿔 새 기록이 계속 쌓이지 않게 하는 것도 함께 검토.
