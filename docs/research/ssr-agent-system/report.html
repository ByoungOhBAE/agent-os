1한 장 요약

영상의 주장: "AI가 똑똑해져도 일하는 '환경'을 안 깔아 두면 일이 줄지 않는다."

영상 시스템은 네 개의 층

  • 스킬 — 반복하는 일을 'AI 단축키'로 저장
  • 세컨드 브레인 — AI가 내 자료를 스스로 찾아 쓰게 길을 깔아 둠
  • 루틴 — 정한 시간에 단축키를 대신 눌러 줌

  • 대시보드 — 위 네 가지를 한 화면에 모아 보는 '겉면'

우리에게 주는 뜻

우리는 이미 스킬·지침 파일·예약 작업·외부 연결을 영상보다 많이 갖고 있음(스킬 171개, 예약 8개). 빈 곳은 ① 업무 전체를 잇는 길잡이(세컨드 브레인 중급), ② 그걸 보는 탐색기, ③ 흩어진 예약을 한눈에, ④ 네 가지를 모은 '오늘' 화면.

영상과 똑같이 따라 하지 않고, 화면 모양은 일부러 다르게(밝은 바탕·노선도 지도) 설계 — 7장.

9한계와 주의

  • 영상 속 대시보드·탐색기의 속 구조(데이터를 어떻게 모으는지)는 화면과 말로만 확인했고 코드는 보지 못함 — '추정'이라 적은 줄은 추정.
  • 프레임은 65장(장면 전환 + 20초마다 보충)만 봤음. 모든 장면을 본 것은 아님.
  • 프롬프트 전문은 영상에서 '고정 댓글 PDF(회원가입 필요)'로만 제공 — 받지 않았고, 이 보고서는 화면에 보인 부분만 씀.
  • 영상 화면은 저작권이 있어 그대로 옮기지 않고 배치만 다시 그림(색·모양도 일부러 다르게).
