# AgentOS 전체 점검 요약 (2026-10-07, 공개용)

전체 보고서는 보안 약점(열린 경로·차단 공백·자격 정보 위치)을 담고 있어 공개 저장소에 올리지 않고 운영자 PC에만 둔다.
이 문서는 숫자와 방향만 남긴다. 계획: `docs/plans/agentos-전체점검-개선샘플-계획.md`.

## 방법
- 6개 영역(지시 충돌·스킬/하네스·봇 분류·봇 산출물 진실성·운영/비용·보안)을 3회 점검.
- 1회차 → 독립 검수(근거 명령 재실행) → 2회차(1회차 결과를 못 보는 블라인드) → 독립 검수 → 주제별 대조 → 3회차(차이난 주제만 재조사).
- 봇 15개에게 읽기 전용 자기점검 인터뷰(함정 질문 2개 포함)를 실제로 보내고, 답을 설정 파일과 기계적으로 대조.
- 스크립트: `scripts/audit/` (snapshot, bot-probe, grade-probe, consolidate, build-report, cc-watch, cc-shoot).
