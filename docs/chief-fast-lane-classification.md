# 비서실장 작업 분류안 — 바로 처리 / 승인 필요

상태: **초안 (비서실장 지침에 아직 적용하지 않음)**. 근거: 현재 봇 목록과 지난 작업 HER-4~HER-21.

## 판단 기준

아래 5개를 **모두** 만족하면 "바로 처리", 하나라도 아니면 "승인 필요".

1. 결과물이 **글·보고서·시안**이고 사장님께만 전달된다 (밖에 공개·발송하지 않음).
2. 파일·코드·홈페이지·봇 설정·기억·스킬을 **바꾸지 않는다** (읽기·검색만).
3. 그 일을 맡을 **기존 봇이 있다** (새 봇·부서 필요 없음).
4. 추가 비용이 없다 (구독 안에서 처리, 유료 서비스·결제 없음).
5. 수강생 개인정보·비밀값을 다루지 않는다.

애매하면 **승인 필요**로 본다.

## 바로 처리 (계획 승인 없이 기존 봇에게 배정)

| 작업 | 담당 봇 | 조건 |
|---|---|---|
| 블로그 제목·설명 아이디어, 글 초안 | 콘텐츠_블로그제목 | 게시는 하지 않음 |
| SNS 홍보 문구 초안 | 콘텐츠_SNS문구 | 게시는 하지 않음 |
| 유튜브 영상 분석 보고서 | 콘텐츠_유튜브분석 | 공개 영상, 보고서만 |
| 쓸 만한 스킬 찾아 추천 | 대시보드개선_스킬탐색 | 추천만, 설치 안 함 |
| 화면 디자인 시안 | 대시보드개선_화면디자인 | 시안만, 코드 반영 안 함 |
| 자료 조사·요약·비교 | 주제에 맞는 기존 봇 | 웹 읽기만 |
| 사장님이 준 글 교정·요약·번역 | 주제에 맞는 기존 봇 | — |
| 진행 상황·지난 결과 질문 | 비서실장이 직접 답 | 배정 불필요 |

## 승인 필요 (지금처럼 계획 → 승인 카드 → 진행)

| 작업 | 이유 |
|---|---|
| 새 봇·부서 만들기, 조직도 변경 | 조직 구조가 바뀜 |
| 봇의 기억·스킬·설정 변경, 스킬·프로그램·커넥터 설치 | 봇 동작이 바뀜 |
| 코드 수정·구현 | 파일이 바뀜 (다른 작업과 충돌 가능) |
| 홈페이지 반영·배포 | 실제 서비스가 바뀜 |
| 인스타·블로그 실제 게시, 메일·메시지 발송 | 밖에 공개됨, 되돌리기 어려움 |
| 파일 삭제·이동 | 되돌리기 어려움 |
| 비용이 드는 작업 (유료 API·결제) | 돈이 듦 |
| 수강생 개인정보·비밀값 관련 | 보안 |
| 봇 3개 이상이 나눠 해야 하는 큰 작업 | 순서·역할 설계가 필요 |

## 바로 처리 방식

1. 요청 이슈에 한 줄 댓글: "바로 처리합니다 — 담당: ○○, 결과물: ○○". 사장님이 멈추고 싶으면 댓글로 말하면 된다.
2. 기존 담당 봇에게 하위 작업 1개 배정 (완료 기준 포함).
3. 결과를 완료 기준과 **한 번** 대조한다. 실패 신호가 있을 때만 추가 확인한다.
4. 짧은 보고 (한 줄 요약 · 결과물 · 확인표) 후 `done`.

**도중에 멈추는 경우:** 담당 봇이 승인 필요 목록의 일(설치·게시·파일 수정·새 봇 등)을 해야 한다고 판단하면 거기서 멈추고 승인 경로로 바꾼다.

## 적용 후 확인할 것

- 바로 처리 작업은 승인 카드 없이 끝나고, 승인 필요 작업은 여전히 승인 카드가 생기는지 (각 1건 이상 실제 요청으로 확인).
- 같은 종류 작업(예: 블로그 제목 5개)의 요청→완료 시간을 이전과 비교.
- 지침 변경 전 백업을 남기고, 문제가 있으면 이전 지침으로 되돌린다.
