### 디자인 규칙 (설치된 스킬 기준 — 지시서에 체크리스트로 넣을 것)
- kpi-dashboard-design: KPI 5~7개 제한, 숫자 옆 비교(지난주 대비), 빨강=나쁨·초록=좋음 일관, 요약→상세 드릴다운, 계산 방법을 카드에 한 줄로 공개("토큰 = heartbeat-runs usageJson 합").
- web-accessibility-wcag: 색만으로 상태 표시 금지(글자 병기), 대비 4.5:1, 키보드로 카드 이동·Enter로 열기, 의미 있는 제목 구조.
- 기존 호스트 토큰(`--foreground`, `--muted-foreground`, `--border`, `--card`, `--accent`)만 사용. **정정(10-07 01:59, HER-113 막힘 보고 반영):** 의미 색 3개 `--destructive`(나쁨)·`--agentos-lamp`(좋음)·`--agentos-brass`(주의)는 아이콘·막대·테두리·띠 배경에만 추가 허용, 글자 색은 다섯 토큰 유지. 처음 명세는 이 줄과 '빨간 띠·주황 경고' 요구가 모순이었음(명세 작성자 실수). 한국어, 비개발자 문장.
- 반응형 390 / 768 / 1440에서 넘침·한 글자 줄바꿈 없음.
- 카드 클릭 → 기존 상세 팝업과 같은 형식(무엇·왜·상태·출처).
