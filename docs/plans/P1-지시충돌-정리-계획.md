## 1. 무엇이 부딪치는가 (쉬운 말)
봇은 일할 때 여러 안내문을 동시에 읽습니다: 공통 지식(모든 봇), 봇 지시서(SOUL), 사장님 성향 메모(USER.md), 그리고 실제로 막는 장치(가드).
이 안내문끼리 말이 다르면 봇이 헷갈리거나, 시킨 대로 했는데 가드에 막힙니다.

| T01 | 공통 지식: "한글 본문은 Python urllib로 보내라" | 봇 지시서·가드: "스크립트 안에서 PATCH/POST 하면 막힌다" | 공통 스킬 15개 프로필 · 검수 봇 SOUL 1곳에 urllib 문장 |
| T03 | 검수 봇 지시서: 반려는 `## 반려 #n` + 위치/위반 기준/수정안 3줄 | 같은 지시서 아래쪽: 표 양식 `**반려** \| # \| 무엇이 …` (가드가 막는 양식) | 검수 SOUL에 '## 댓글 형식' 절 1곳 |

## 2. 바꿀 내용 (문구 안)
원칙: **가드가 실제로 허용하는 방식에 글을 맞춘다.** 가드는 바꾸지 않는다.

- **T01** 공통 지식(`knowledge/data/registry.json` common 항목) →
  "댓글·문서는 Python urllib(UTF-8, ensure_ascii=False)로 보내도 됩니다. **작업 상태 변경(done/in_progress/blocked)**은 가드가 본문을 읽을 수 있게 `curl -d '<JSON>'` / heredoc / 미리 만든 파일(`-d @절대경로`) 중 하나로만 보냅니다."
  같은 내용으로 검수 봇 SOUL 60행·검수 봇 전용 지식 항목·블로그제목 스킬의 해당 문장도 교체. `memory-knowledge.mjs apply` + `translate`.
  확인: 가드 시험에 "urllib 댓글 POST → 통과 / 스크립트 안 상태 PATCH → 차단" 2개 추가(지금 동작을 고정).
- **T03** 검수 봇 SOUL(손으로 관리하는 파일, 백업 후) '댓글 형식' 절 → 가드 양식 하나로:
  반려 = `## 반려 #n` + `- 위치:` `- 위반 기준:` `- 수정안:` (표는 그 아래 덧붙임으로만), 승인 = `## 완료` 4항목.
- **T04** 사장님 성향 메모의 커밋 문장(`registry.json` user 항목) →
  "커밋은 작업 지시와 봇 역할이 허용할 때만, 정해진 작업 브랜치에서 합니다. 비밀값·무관한 파일은 넣지 않습니다."
  그리고 이 항목을 **코드 작업 봇에만** 배정(결정 D-P1-1).
- **T05** SNS문구 봇 지시 원본(Paperclip AGENTS.md) 37행 →
  "연락 경로는 '학원 문의' 한 줄 또는 [확인 필요]로만 씁니다." 후 `sync-soul`(검수 SOUL 백업 먼저).
