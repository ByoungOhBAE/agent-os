## 4. A안 설계
- **사이드바**: 각 프로젝트 아래에 ▸칸반 / 작업계획 / 루틴 / 산출물을 둔다. 현재 URL의 프로젝트만 자동으로 펼치고 나머지는 접는다. 행 스타일은 `.plugin-sidebar-nav-item`으로 네이티브 행과 정렬한다.
- **페이지** `/:prefix/project-hub?project=<id>&tab=kanban|plan|routines|outputs`(모달이 아니라 페이지 안에서 렌더):
  - 칸반: projectId 필터를 건 이슈를 상태 열로 보여준다(읽기 전용). 카드를 누르면 네이티브 이슈로 이동한다.
  - 작업계획: 프로젝트 cwd를 work-plan 폴더에 대응시킨다(BFF가 cwd에서 폴더 id를 찾는다). 대응이 없으면 "폴더 미연결"로 표시하고 0건으로 표시하지 않는다.
  - 루틴: projectId 필터를 건 루틴과 최근 실행 이력을 보여준다.
  - 산출물: 결정 필요(아래 Q2).
- **미분류**: projectId가 없는 이슈 26개와 루틴 1개는 "미분류" 묶음으로 따로 보여준다. 자동으로 다시 배정하지 않는다.
