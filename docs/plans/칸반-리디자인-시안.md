## 0. 이번 시안의 범위와 한계
- 대상: 왼쪽 메뉴 **프로젝트별 › 칸반**(프로젝트 허브 플러그인). 실제 봇 작업(Paperclip 작업)이 보이는 칸반입니다.
- 비교 방법: 운영 화면을 그대로 띄우되, **검사용 브라우저 한 개에만** 새 번들을 끼워 넣어 같은 실데이터로 전/후를 찍었습니다. 운영 파일·다른 브라우저는 바뀌지 않았습니다(G2가 해시로 확인).
- 이번에는 **스킬 지도 방식을 제가 직접 따라 했습니다.** 비서실장 → 봇 경로로 돌린 것은 아닙니다(봇 설정 변경은 확정 뒤).
- 실데이터에는 지금 진행 중 작업이 0건(완료 25 · 취소 53)이라, 진행 중 카드 모양은 `[예시]` 표시가 붙은 가짜 작업 14건으로 따로 보여줍니다. 예시 화면은 모양 설명용이지 증거가 아닙니다.
- impeccable은 실행 파일을 받지 않고 **참고 문서만** 읽었습니다(critique · operate · distill · clarify · layout). 그래서 impeccable 자동 검출기(detector)는 돌리지 않았습니다.

## 3. 남은 것 (이번 시안에서 안 함)
- **F1 칸반 두 개 문제** — 결정(2026-10-04): 업무 › 칸반을 **전체 프로젝트 칸반 링크**로 변경(`/HER/project-hub?project=all&tab=kanban`). 옛 Hermes Kanban 인페이지 보드는 폐기, Hermes Kanban 데이터·BFF API는 그대로 둠.
- 필터 상태를 주소(URL)에 남기기(web-design-guidelines "URL reflects state") — 확정 시 추가 가능.
- 요약 칩 순서(주의 먼저)와 열 순서(업무 흐름)가 다른 점 — 넓은 화면에서는 업무 흐름 순서 유지, 좁은 화면에서는 주의 먼저로 바꿈.
- 비서실장 → 봇 경로로 같은 결과가 나오는지는 공용 스킬 폴더 연결 후 별도 시험.
