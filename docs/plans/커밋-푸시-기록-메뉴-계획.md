## 2. 목표

프로젝트 허브(왼쪽 메뉴의 프로젝트별 묶음: 칸반·작업계획·루틴·산출물)에 **「커밋·푸시」 탭**을 추가해, 프로젝트(저장소)마다 아래를 한 화면에서 봅니다.

**요약 줄**
- 아직 안 올라간 커밋 수 (0이 아니면 노란 경고 — 새 커밋·푸시 지침 위반 감지용)
- 마지막 푸시: 언제 · 누가 · 몇 개
- 최근 7일 커밋 수: 주체별(봇 이름 / 사장님·Hermes / 구분 불가)

**목록 (최신순, 한 줄 = 커밋 하나)**
| 칸 | 내용 |
|---|---|
| 언제 | 커밋 시각 (상대 시간 + 마우스 올리면 정확한 시각) |
| 누가 | 봇이면 봇 이름 + 부서·역할 표시 / 사람·Hermes / "구분 불가"(추측하지 않음) |
| 커밋명 | 제목 줄. `HER-xx`가 있으면 작업 링크 |
| 규모 | 바뀐 파일 수, +추가/−삭제 줄 |
| 브랜치 | main 외 브랜치면 표시 |
| 올라감 여부 | ✅ GitHub 반영 / ⏳ 이 PC에만 있음 (몇 시간째) |
| 푸시 | 언제 · 누가 올렸는지 (기록 장치 설치 이후분만) |

**상세 팝업 (줄 클릭)**: 커밋 전체 메시지, 바뀐 파일 목록, 연결 작업·실행 기록 링크, GitHub 커밋 링크, 커밋→푸시까지 걸린 시간.

## 3. 하지 않는 것
- 화면에서 커밋·푸시·되돌리기 같은 **git 쓰기 작업** (보기 전용)
- 커밋 이력 수정, 과거 커밋 작성자 고쳐 쓰기
- Paperclip 본체 수정, GitHub 토큰 사용
- 사람 커밋을 봇으로 "추측"해서 단정하기 (근거 없으면 "구분 불가")

## 4. 설계

### 4-1. 커밋 정보 (읽기 전용)
- 기존 작업계획 방식과 같게: 수집 스크립트가 각 저장소에서 `git log`(읽기 전용)를 읽어 `agentos-git-activity.json`을 만들고 3100에서 제공. 정기 갱신(작업계획 크론과 같은 주기) + 푸시 직후 갱신.
- 봇 구분: 작성자 이메일 `agent-<8자리>@paperclip.local` → Paperclip 봇 목록에서 ID 앞자리로 찾아 이름·부서·역할을 붙임.
- 올라감 여부: 커밋이 `origin/<브랜치>`에 포함되는지로 판단.

### 4-2. 푸시 기록 장치 (새로 필요)
- 각 저장소에 **pre-push 훅**을 달아, 푸시할 때마다 `%LOCALAPPDATA%/agentos/git-activity/pushes.jsonl`에 한 줄 기록: 시각, 저장소, 브랜치, 이전→새 커밋, 개수, **누가**(봇 실행이면 Paperclip이 주는 봇·실행·작업 정보, 아니면 git 서명 이름).
- 원칙: 훅이 실패해도 **푸시를 절대 막지 않음**(항상 통과). 비밀값은 기록하지 않음. 저장소 밖에 기록(공개 저장소로 새지 않음).
- 저장소별 설치(결정 2, 사장님 의견 반영 — rimbus 포함):
  - agent os·academy: `.git/hooks/pre-push` (이 PC에만, 저장소 내용 변화 없음)
  - rimbus: `.githooks/pre-push` **새 파일 하나만 추가**(실행 권한 100755). 기존 `pre-commit`·`commit-msg`·`image-allow.txt`와 `core.hooksPath` 설정은 **건드리지 않음**. 저장소 내용이라 커밋·푸시되며, 다른 PC·봇이 저장소를 받아도 같은 기록 장치가 돈다 → 어느 환경에서도 실패 없이 통과하도록(Windows·WSL·게임 없는 PC) 작성. 기록 위치는 `%LOCALAPPDATA%`가 없으면 `~/.local/state/agentos/`.
  - rimbus 팀 규칙 존중: 변경 내용과 이유를 rimbus `docs/HANDOFF.md`에 기록하고, rimbus 자체 훅 회귀 시험(`docs/review/r11/m0_hook_failopen.sh`, `r2/hook_regress_r2.sh`)을 설치 전후로 돌려 **결과가 같아야** 함. 새 훅 파일 자체도 rimbus 커밋 검문소를 통과해야 함.

### 4-3. Hermes 메인(저)의 커밋 구분
- 지금은 제 커밋이 사장님 이름(`Tahar`)과 같아 구분이 안 됩니다. 앞으로 제 커밋에 **`Agent: Hermes` 표시(커밋 끝 꼬리말)** 를 붙이면 화면에서 "Hermes"로 나뉩니다(결정 3).

## 6. 완료 기준 (검증 게이트 — 승인 후 `GATES-git-activity.md`로)

- G4 읽기 전용: 수집 전후 저장소 파일·브랜치·태그 변화 0
- G5 화면: 1440/768/375 실제 화면에서 요약·목록·팝업 값이 API와 일치, 가로 넘침·오류 0, 스크린샷 육안 확인
