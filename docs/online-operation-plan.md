# 온라인 운영 전환 계획 (초안 — 사용자 결정 전, 실행 안 함)

요청 원문: "완성되면 웹 대시보드를 로컬이 아니라 온라인 환경에 올리고 돌릴생각인데 이렇게 하면 로컬이 켜져야만 돌아가잖아"

## 결론 먼저

맞습니다. 지금은 **대시보드 화면만 온라인에 올려도 PC를 끄면 멈춥니다.**
실제로 일하는 쪽(봇, 봇 로그인, 작업 파일, 대시보드 중계 서버)이 전부 이 PC 안에 있기 때문입니다.
PC를 꺼도 돌아가게 하려면 **화면이 아니라 "일하는 쪽"까지 서버로 옮겨야** 합니다(방식 B).

## 방식 A — 화면만 온라인 (PC는 계속 켜 둠)

지금 구성 그대로 두고, 밖에서 휴대폰·다른 컴퓨터로 **로그인해서 들어오는 통로**만 엽니다(학원 홈페이지에 이미 쓰는 Cloudflare 터널 방식).

- **PC를 끄면**: 전부 멈춤. 화면도 안 열림.
- **비용**: 0원(Cloudflare 무료 범위). 전기료만.
- **해야 할 일**:
  1. 대시보드를 `local_trusted` → 로그인 필수 모드로 전환하거나, 터널 앞에 Cloudflare 로그인 관문을 둠(둘 중 하나는 필수).
  2. 터널 연결(대시보드 3100만 공개, BFF·Hermes 포트는 절대 공개 안 함).
  3. PC 절전·자동 업데이트 재부팅 끄기.
- 작업량: 반나절~하루.

## 방식 B — 전부 서버로 이사 (PC 꺼도 됨) ← 원하시는 것

대시보드 + BFF + Hermes 봇 실행기 + 봇 작업 폴더를 **24시간 켜진 클라우드 서버 한 대**로 옮깁니다. 대시보드와 BFF가 같은 서버에 있으므로 `127.0.0.1:4200` 잠금은 그대로 유지됩니다.

- **PC를 끄면**: 대시보드·단체방·봇 작업 계속 돎. 멈추는 것은 데스크톱 앱 방 뿐(GPU 봇 2개는 구독 Opus 5.5로 전환 완료).
- **비용**: 서버 월 대략 1~4만 원대(메모리 8GB급 기준, 업체 선택 때 정확히 확인). 봇 모델 비용은 지금과 같음(구독은 그대로).
- **해야 할 일**:
  1. 서버 준비(리눅스, 메모리 8GB 이상 권장 — NAS는 메모리 2GB라 부족).
  2. Paperclip 설치 + 지금 DB·회사·에이전트 데이터 이전(이전 전후 개수 대조).
  3. 대시보드를 로그인 필수 모드로 전환 + 인터넷 주소 연결(Cloudflare 터널 또는 도메인).
  4. Hermes 설치 + 봇 프로필 이전. **구독 봇 4개는 서버에서 다시 로그인** 필요(로그인 정보는 복사해 가지 않음). 구독 약관상 서버 사용 가능 여부는 이전 전에 확인.
  5. ~~로컬 GPU 모델 봇 2개 처리 결정~~ → 결정·적용됨(2026-09-27): Claude 구독 Opus 5.5. 서버에서도 구독 로그인만 하면 됨.
  6. 봇 작업 폴더는 git 저장소로 서버에 받아서 사용.
  7. BFF의 봇 설정 파일 경로(지금 Windows 경로)를 리눅스용으로 바꾸고 테스트 다시 통과.
- 작업량: 2~4일. 이전 중 1~2시간 정지.

## 방식 C — 혼합 (서버 상시 + PC는 GPU 작업 도우미)

방식 B로 옮기되, GPU 봇만 PC에 남겨 **PC가 켜져 있을 때만** 서버에 붙어서 일을 받게 합니다.

- **PC를 끄면**: 대시보드·단체방·대부분 봇은 계속 돎. GPU 봇 2개만 "꺼짐"으로 표시.
- **비용**: 방식 B와 같음 + 서버↔PC 사설 연결(Tailscale 등 무료 범위).
- **해야 할 일**: 방식 B 전부 + PC와 서버 사이 암호화 사설 연결 + 봇이 서버/PC 어디서 도는지 대시보드에 표시하는 작업.
- 작업량: 방식 B + 2~3일. 구조가 가장 복잡.

## 보안 전제 (어느 방식이든 필수)

- 인터넷에 여는 것은 **대시보드 화면(로그인 필수) 하나뿐**. `local_trusted` 상태 그대로 공개 금지.
- BFF(4200), Hermes 창구(9119), 봇 실행기(8645)는 절대 외부 공개 안 함. BFF만 봇 열쇠를 쥐고 있기 때문.
- 봇 키·로그인 정보는 채팅·저장소에 남기지 않음.

## 추천

- **지금 바로 밖에서 보고 싶다** → 방식 A (비용 0, 하루).
- **PC를 끄고도 돌아가야 한다(말씀하신 목표)** → 방식 B. 결정할 것은 두 가지: ① 서버 업체/예산 ② GPU 봇 2개를 어떻게 할지.
- 방식 C는 GPU 봇을 꼭 계속 써야 할 때만.
