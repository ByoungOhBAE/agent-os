## 작업 순서
1. `baoyu-diagram` 설치(`npx skills add jimliu/baoyu-skills@baoyu-diagram` → SKILL.md를 고정 커밋으로 검토 후 `skill_manage`로 Hermes에 등록). 검토 항목: 스크립트가 외부 호출을 하는지.
2. 글 구성안(목차 + 각 절의 시각 자료 지정) 작성 → `docs/blog/outline.md`. **여기서 사장님 1차 확인**(목차·그림 8장 목록).
3. 다이어그램 8장 제작(SVG 4 + HTML 컴포넌트 4). 각 SVG는 브라우저 스크린샷으로 겹침·잘림 확인.
4. 본문 집필(`claude-design` 가이드로 페이지 레이아웃, `humanizer`로 문장) — 보고서 수치·인용 원문 대조.
5. 부록(카드 45·소스) 접이식으로 삽입, 링크 유효성 재확인(verify.py 결과 재사용).
6. 검증(아래) → 커밋 → 사장님께 파일 전달.

## 위험과 대응
- SVG를 손으로 그리면 텍스트 겹침이 잦음 → 스크린샷 검증 필수, 한 장씩 고침.
- 다크 테마(baoyu-diagram 기본)가 블로그 톤과 안 맞을 수 있음 → 색만 밝은 팔레트로 바꿔 씀(스킬은 팔레트 교체 허용).
- 본문 재구성 중 의미 왜곡 → 원칙별 "무엇·왜·어떻게" 3요소를 그대로 유지, 인용은 원문 복사.
