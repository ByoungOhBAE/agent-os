## Description

```
In this video, I'm showing you how to set up and use Agent Teams in Claude Code a collaborative workflow where multiple AI agents can communicate with each other and work together on a shared task. Unlike standard sub-agents that work in isolation, Agent Teams allow for true collaboration between team members, coordinated by a main team lead agent.

📌 What This Video Covers:

Understanding the difference between sub-agents and Agent Teams
Installing Claude Code CLI on your system
Enabling Agent Teams through environment variable configuration
Installing and setting up Tmux for session management
Creating a Tmux session for your Agent Team
Launching Claude Code inside the Tmux session
Using the Start Agent Teams command to spawn your team
Navigating between agents using Tmux commands
Sending commands to individual agents directly
Detaching from the session and letting the team work in the background
Reattaching to the session to review progress
Creating multiple Agent Teams for parallel workflows

⚙️ How It Works:
Agent Teams in Claude Code create a collaborative environment where a main agent acts as team lead and coordinates with teammate agents. These teammates can communicate with each other autonomously, share information, and work together on a shared task all while reporting back to the main agent. Combined with Tmux, the entire team can run persistently in the background, even after you disconnect.

🛠️ Prerequisites:

Claude Code CLI installed on your system
Tmux installed on your system
Basic familiarity with terminal or command prompt
🔗 Resources Mentioned:

Claude Code Documentation: https://code.claude.com/docs/en/agent-teams
Tmux Installation Guide: https://github.com/tmux/tmux/wiki/Getting-Started
Environment Variable Configuration: Check comments section
```
