## 사용자 요청과 승인 범위
사용자는 유튜브 링크와 분석 에이전트를 선택해 실행하면 영상 내용 정리·상세 설명·요약 및 가능하면 핵심 장면 이미지를 받고, 실제 작업 진행을 시각적으로 보길 원합니다. 먼저 비서실장이 find-skills로 유용한 스킬을 찾아 분석 담당에 탑재하고, 실제 가능한 것을 사용자에게 보여준 다음 UI 개발을 이어가기로 했습니다.
사용자는 이번 대화에서 '예전 문서들을 검수하고 맞지 않는 부분을 최신 버전으로 교정하고 본작업 시작'을 지시했고 선행 AI 작업 종료도 확인했습니다. 주 세션이 문서 검수·교정을 마쳤습니다. 이 요청은 **스킬·능력 준비 단계**만이며 UI 구현 승인은 능력 시연 뒤에 받습니다.

## 확인된 운영 사실
- 당신은 Paperclip의 비서실장이며 실제 hermes_gateway 프로필 pc-ebb0943f를 사용합니다.
- find-skills, paperclip/omh-plan, agentos-chief-of-staff가 당신 프로필에 존재합니다. 이름이 모호하면 경로로 읽으세요.
- Paperclip gateway 스킬 API의 desiredSkills는 실제 설치 증거가 아닙니다(supported:false). Hermes 대상 프로필의 스킬 원문·스크립트·실행 결과를 확인해야 합니다.
- 기존 탐색 담당 대시보드개선_스킬탐색이 있으니 무관한 역할·기억을 바꾸지 않고 재사용 가능성을 검토하세요. 분석 전용 담당은 콘텐츠_유튜브분석을 권장하되 중복 이름과 역할을 먼저 확인하세요.

## 계획과 실행 절차
1. 원래의 비서실장 단일 창구 규칙대로 계획 문서와 확인 카드를 먼저 작성하세요. 이 요청의 범위·금지사항을 그대로 넣고, 스스로 승인하지 마세요. 주 세션이 사용자의 시작 지시와 범위가 일치하는지 확인한 뒤 승인 전달을 처리합니다.
2. 승인 후 find-skills로 자막/타임스탬프, 음성 전사, 영상 프레임 추출, 장면 선별·이미지 이해, 출처 있는 보고서 기능을 조사하세요. 로컬 youtube-content도 비교하세요. 외부 후보의 원문·관련 스크립트·고정 커밋·라이선스·전송 대상·비용·권한·Windows/WSL 호환성을 검토하세요.
3. 별도의 분석 담당에 필요한 스킬만 탑재하고 실제 프로필에서 확인하세요. 새 봇은 최대 1개, 같은 역할이 이미 있으면 재사용. 기존 탐색 봇은 조회·조사만 맡길 수 있습니다. 승인된 분석 프로필 외 다른 프로필, 기본 프로필에는 쓰지 마세요.
4. 안전하게 사용 가능한 공개/허가된 샘플로 실제 능력을 시험하세요. 사용자가 대표 링크를 아직 주지 않았으므로 시험 자료의 URL·라이선스·언어·길이를 명시하고 사용자 영상의 대표성은 미검증이라고 표시하세요. YouTube 접근이 막히면 오류를 그대로 보존하세요. 임의 쿠키 복사·로그인 대행·유료 API 전환·접근 제한 우회는 금지합니다. 사용자 제공 영상이 필수라면 그 단계만 blocked로 보고하고 스킬·도구 검증은 완료하세요.
5. 실제 프레임·자막과 연결된 한국어 샘플 보고서 및 기능별 검증됨/조건부/불가 표를 비서실장이 검토해 report 문서로 제출하세요. 자막만 읽은 결과를 영상 전체 이해로 부르지 말고 실제 프레임과 생성 이미지·썸네일을 혼동하지 마세요. 자동 자막, 화면 관찰, 보충 해설을 구분하세요.
